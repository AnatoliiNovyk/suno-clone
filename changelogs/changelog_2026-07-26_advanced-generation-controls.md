# changelog_2026-07-26_advanced-generation-controls

## Зміна
На сторінці «Розширений» додано Suno-подібні контроли генерації (секція «Стиль та жанр»):

- **Вокал** (Будь-який / Чоловічий / Жіночий) — сегментований вибір; вплітається у промпт (`Vocals: male/female voice.`).
- **Химерність (Weirdness)** — слайдер 0–100%, мапиться на реальний `generation_config.temperature` (0.0–1.0).
- **Вплив стилю (Style Influence)** — слайдер 0–100%; >66% → «Strictly adhere to the {genre} style», <33% → «Loosely inspired by {genre}…», 33–66% — нейтрально (у промпт).

Технічно:
- `python-service/main.py`: `GenerateRequest` отримав `temperature`, `vocal_gender`, `style_influence`. `_build_input_text()` вплітає вокал і вплив стилю; `_create_interaction()` збирає `generation_config` з непорожніх `seed`+`temperature` із тим самим fallback (при відхиленні `generation_config` моделлю — повтор без нього).
- `suno-clone/src/components/ui/RangeSlider.tsx` — новий перевикористовуваний слайдер (підпис, %, кнопка скидання до дефолту), стилізований під дизайн-систему (`primary-500`, `shadow-glow-orange`).
- `suno-clone/src/pages/AdvancedPage.tsx` — три контроли + прокидання у `generateMusic`. `generateApi.ts` — нові опційні поля payload.

## Як було до зміни
Розширена сторінка мала лише текстові поля (опис, жанр, настрій, negative prompt) + seed. Не було візуальних контролів на кшталт Suno (повзунки, вибір вокалу) для швидкого керування звучанням — усе доводилось описувати словами в промпті.

## Що покращує зміна
- Знайоме за Suno керування: вокал, «химерність», сила стилю — швидко, без формулювань у тексті.
- Чесність можливостей: **Duration навмисно не додано** — Lyria 3 не контролює точну тривалість через API (модель обирає її сама; для короткого кліпу є режим «Семпл»). Показувати нефункціональний слайдер тривалості означало б вводити користувача в оману.
- `temperature` — реальний параметр API з fallback: якщо прев'ю-модель не підтримає `generation_config`, генерація все одно пройде (лог `[WARN] retrying without it`), а вокал і стиль (через промпт) працюють завжди.
