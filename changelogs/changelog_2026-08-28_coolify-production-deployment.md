# Підготовка production-розгортання у Coolify

Раніше проєкт мав лише локальні команди запуску: не було Docker-образів,
healthcheck-ів, reverse proxy або відтворюваної схеми розгортання монорепозиторію.

Тепер Docker Compose для Coolify збирає окремі ізольовані контейнери фронтенду
та FastAPI, публікує лише Nginx, передає API через внутрішній `/api` proxy,
перевіряє готовність сервісів і документує безпечне налаштування production
змінних та Supabase webhook-ів.
